# NR link-level simulation from zero

A series of short notebooks that explain, from the ground up, what this repository's link-level simulator (`nrdlsim`) does and why. It is written for someone who knows Python and a little numpy but nothing about wireless.

Each notebook answers one question in 15–20 minutes, and all of them use one running example: a 20 MHz carrier at 3.5 GHz, a base station with 4 antennas and a phone with 2. Every notebook follows the same pattern:

- **In one sentence**: the idea, before any detail.
- **Intuition first**: an analogy or a picture before an equation.
- **Build it by hand, then use the library**: a few lines of numpy, then the `nrdlsim` function that does the same.
- **Predict first, then run**, and **What you see** after each result.
- **Check yourself**: small quizzes with hidden answers.
- **Where in the code** and **Going further** (the 3GPP specifications) at the end.

## Reading and running them

- **Read on GitHub.** The notebooks are stored with their outputs, plots included.
- **Run in your browser.** Click *Open in Colab* (a Google account is needed). The first code cell installs `nrdlsim` from GitHub. If a link doesn't open, choose *File → Open notebook → GitHub* in Colab, enter `HelloSYQ/Claude`, and pick the notebook.
- **Run on your computer.**

  ```bash
  git clone https://github.com/HelloSYQ/Claude.git
  cd Claude
  pip install -r requirements.txt jupyterlab ipywidgets
  jupyter lab notebooks/learn
  ```

  `ipywidgets` is optional: it adds the sliders.

## For maintainers

The notebooks are generated by [`build_learn.py`](build_learn.py). Edit the script, not the notebooks, then regenerate them with their outputs:

```bash
pip install -e ".[notebooks]"
python notebooks/learn/build_learn.py --execute
```

`tests/test_learn_notebooks.py` runs every code cell, so a change to `nrdlsim` that breaks a notebook fails the tests.
